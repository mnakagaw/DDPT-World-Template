# 国別版の開始依頼文

短い依頼で開始できる。利用者が指定するのは国名でよく、既存の案件指示がある場合は併せて使う。

```text
https://github.com/mnakagaw/DDPT-World-Template を参照して、［国名］版を作って。
```

AIへ作業範囲を詳しく渡す場合は、次を使用する。

```text
対象国：［国名］
参照リポジトリ：https://github.com/mnakagaw/DDPT-World-Template

このPrivateリポジトリを既存のGitHub認証で読み取り、START_HERE.mdとAGENTS.mdから作業を始めてください。国名を正規化し、既存案件の指示・保存先・資産を確認してください。AIが調べて埋められる項目を私への質問票にせず、国を一意に特定できない等、成果が変わる重要な曖昧さだけ確認してください。

docs/COUNTRY_AGENT_WORKFLOW.md、docs/IMPLEMENTATION_CONTRACT.md、共通仕様C01～C07、国別データ適応規則に従ってください。DDPTの「地域から多分野を読む」「テーマから地域間を比較する」の目的、情報配置、地域選択の連動、出典と欠測、計画資料への経路を維持してください。善意の独自変更で主要導線や操作の意味を変えないでください。

新しい出力先へcreate-country.mjsを実行し、初期データを確認してください。World Bank全国値とgeoBoundaries ADM1の収集だけで止まらず、現地統計局、国勢調査、公式地域コードと行政区分、地方計画・計画様式、公開予算・事業、取得可能な住民参加資料を調べてください。同条件で利用できる国内の公式一次資料を優先してください。

公開API、Excel、PDF等から実際に資料を取得し、docs/SOURCE_ADAPTER_GUIDE.mdに沿った再実行可能なアダプターで地方値と計画資料をデータ契約へ追加してください。コード体系と境界版を根拠で照合し、provider IDを公式コードと扱わないでください。全国値の地方への代用、出典のない推定、欠測のゼロ化、未取得資料からの計画不存在・承認判定をしないでください。

取得可能な情報の粒度・期間・頻度に合わせて図表と機能を適応してください。地図なしなら一覧、時系列なしなら実在する時点を使い、保留機能には理由と代替作業を示してください。文章生成・保存・各出力形式の採用自体は国の資料と業務で判断してください。

計画・予算／財政・実施報告・公式評価を調査の観点として確認し、制度名、対象階層、周期、会計年度、公式状態と尺度、資料ごとの取得・更新・利用条件をAIが記録してください。４区分を必須の同じカードやページにせず、SISMAP、ウガンダの章構成、５年周期を全世界に当てはめないでください。既存の投資・財政機能から同じ資料を参照する方法も使ってください。

docs/PLANNING_DATA_CONTRACT.mdを読み、設計用country-profileとruntimeのdata/dashboard.json内の任意のplanningを分けてください。公開された優先資料の本文を取得・抽出・原本照合し、地域の同定、対象期間、出典箇所を残してください。リンク確認、本文取得、内容確認と公式状態を分け、要約・課題・目標・財政・実施結果・評価は根拠のある範囲で表示・出力してください。評価点を執行率や達成率へ読み替えず、統計年で会計年度・複数年計画を隠さないでください。地図の既定は資料収録状況とし、公式状態の表示は対象区分・資料期間・状態定義と証拠を揃えた場合だけ採用してください。

実データのある地域と不足する地域で、地域選択→診断／比較→計画資料→採用出力が動作するローカルサイトを完成させてください。データ検証、ブラウザ操作、実際の取得物の地域・期間・単位・代表値・出典を確認し、結果と未検証範囲を記録してください。起動しただけ、リンクを収集しただけで完成と報告しないでください。

確認済み資料・原本・変換処理・未結合・不足・次の取得行動を台帳へ残してください。資料不足時も取得済みの根拠・原資料・補完欄で作業できる代替を完成させてください。更新失敗時は最後の正常版を保持し、元資料の更新停止とサイト生成・配備の失敗を分けて説明してください。HANDOFF.mdに完了工程、途中工程、原本と抽出位置、再実行コマンド、最終成功版、次の具体的作業を保存し、再開時はそこから続けてください。初期収集だけの段階は収集途中として扱ってください。

この案件で公開先やGitHub作成まで指示している場合は、その依頼範囲まで進めてください。指示がなければローカルのサイト・データ・アダプター・採用出力・検証記録までを既定とし、別のリポジトリや公開先を勝手に作らないでください。最後に、できること、対象地域・時点・収録範囲、再構築方法、制約と未完了作業を簡潔に示してください。
```
