# 0.3 計画・資料機能の検証

検証日：2026-09-13。実行パッケージ0.3.0、データschema 0.2、Windows／Node.js v24.11.1／Codex In-app Browser。改修の起点は`1cfe4b90d666ff9e0f976424609513ab93f98200`。今回試験したコードと各データのSHA-256は[検証manifest](evidence/planning-v0.3-manifest.json)に記録した。公開後の対象commitとCIは末尾のリリース記録を参照する。

## 実装した範囲

- 国別担当は公式の統合システム、分散する計画・予算・実績・評価、一部資料だけ取得できる状況を情報源ごとに調べ、採用機能を決める。AIが国名から開始シートとTask Contractを埋め、原本保存・照合・変換・生成・検証まで続ける手順を更新した。
- 任意の`dataset.planning`で名称・制度・周期・採用区分・出力・地図の意味・関連ページ・情報源の更新状態を指定する。計画本文、優先事項・目標、予算等の数値、公式評価を期間・定義・単位・根拠とともに表示する。取得工程の詳しい内訳は補助情報へ移した。
- 資料の取得段階、制度上の状態、公式評価、予算執行、計画達成を分ける。公式状態の地図は資料区分と対象期間を固定し、照合根拠のある状態だけを使う。矛盾した状態は競合表示にする。
- 資料CSVを任意出力として追加した。Markdown／HTMLにも取得済み資料・所見・根拠・不足を反映する。未採用の資料区分に属する取得資料も追加資料として残す。
- 再構築は候補の検証と一時領域での生成を終えてからサイトを入れ替える。生成・メタデータ書込みに失敗したときは従来のサイトとデータを保持し、停止を表示する。旧サイトをバックアップへ残す。

## 互換性と地域選択

任意拡張のない旧schema 0.2データを再生成して確認した。従来のURL、統計CSV、Markdown／HTML／Evidence CSVの3出力とファイル名を維持する。既存メモの保存形式は変更していない。旧資料の自由記述の取得状態を新たな「確認済み」の根拠へ格上げしない。

市を選択後、**同じ所属先の上位地域をドロップダウンから選び直しても、市を解除して上位全体を優先する**。所属を示す表示と、親全体を選択するoptionを分けるため、同じoptionを選び直してchangeが起きない問題を避けられる。指標と統計年は保持する。親の資料・値がなければ、その親の不足を表示し、子の資料を残したり合算したりしない。

新しい資料照合情報は内部`territory_id`も固定し、資料側のIDとの完全一致を要求する。公式コードが双方null、地域型・コード体系・境界版が同じ地域間でも誤配属を拒否する。これは旧データに拡張を必須化する変更ではない。

旧版で生成済みのHTML自体は新しい更新停止sidecarを読まない。停止表示を導入するには、旧データを0.3で一度正常に再生成する。実行時の外部npm依存、有料契約、認証情報、無人AI API呼出しは追加していない。

## 実資料によるA・B・Cの確認

これらは国の固定分類ではなく、今回確認できた地域・資料・期間の組合せである。短い監査済み抽出、原本のハッシュ、変換処理、再実行方法は[実資料の再現例](../examples/planning-evidence/README.md)に記録した。原本PDF・HTMLはGit対象外のローカル証拠領域に保持し、全文をリポジトリへ再配布していない。

| 条件 | 実際に取得・照合した資料 | 画面・出力での確認 |
|---|---|---|
| A 公式システム | [SISMAP MunicipalのMoca](https://www.sismap.gob.do/municipal/organismoevidenciasmunicipales/id/20913)、掲載されたPMD 2024–2028 | 計画本文とSISMAP指標2.02の100%を別資料として表示。評価のスナップショットを計画達成率や法的承認と呼ばない。計画の食料安全保障に関する優先事項は該当ページを付け、数量目標を補わない。 |
| B 分散資料 | [Yumbe DDP III](https://yumbe.go.ug/sites/default/files/publications/YUMBE%20DDPIII%20221111_edited%20ddp_yumbe%20dlg%201.pdf)、[FY2024/25 Q3財政報告](https://budget.finance.go.ug/sites/default/files/Indivisual%20LG%20Budgets/934%20Yumbe%20District%20Quarter%203.pdf)、[LGPA 2018](https://budget.finance.go.ug/sites/default/files/yumbe_district_assessment_lgpa_full_report-compressed.pdf) | 計画2020/21–2024/25、年度予算、Q3までの累積収入、2018年の評価を区別。予算64,846,977、修正予算68,579,647、累積収入53,862,674は原表のUGX thousands。LGPAのAccountability Requirements 50%は歴史的評価として定義と範囲を付けた。 |
| C 部分取得 | [Adjumani公式出版物一覧](https://adjumani.go.ug/publications) | 計画期間の掲載は確認できるが本文は未取得と表示。Yumbeから変更後にYumbeの資料・金額が残らず、公式一覧への入口と未取得事項を表示。 |

Yumbe報告の支出額は表と本文で一致せず、本文の単位表記にも疑義があるため採用せず、地域別gapに理由を残した。予算コードと統計コードの体系も異なるため、公式コード・境界の対応を未照合としている。名前だけで新旧地域の統計を合算していない。Adjumani一覧から個人メール閲覧画面へのリンクは追跡せず、成果物には公式一覧のURLだけを採用した。

実資料データ版は両国とも`2026-09-13T07:12:03.779Z`。全国人口だけWorld Bank APIの保存済みJSONを使い、最新非欠測年2025、DOM 11,520,487、UGA 51,384,894をそれぞれ全国にのみ格納した。地方人口・境界は今回の実例へ補っていない。固定した取得時点の資料による例であり、自動更新中とは表示しない。

## 合成データによる境界条件

合成国TSTのA／B／Cと旧0.2fixtureは、架空であることをデータと画面に表示し、実資料の例・初期収集器に混ぜていない。

- A：計画・予算・実績・評価、根拠付き制度状態、観測値0、評価尺度、同名の市と県を検証。
- B：分散資料、未照合の抽出、情報源の更新停止、採用区分外の取得資料を残すことを検証。
- C：本文なし、出力形式未採用、国の参考資料と選択地域の資料の分離を検証。
- 市→同じSubregion、同じRegion、別Region、資料のない親、再読込・URL復元は既存の階層回帰を維持。計画ページでも同じ親への切替を実操作で確認。
- 公式状態による着色・競合・対象期間の厳密一致は合成データで検証した。実資料の例では法的承認を確認しておらず、この着色を実データの承認確認結果として扱わない。

## 未実施・適用限界

実機スマートフォン、実際の200%文字拡大、支援技術全般、正式な印刷PDF、自治体職員の実利用試験は未実施。スマートフォン検証はデスクトップブラウザーのviewportによる。生成HTMLは既存の折返し付き基礎資料形式を維持しており、国別の正式Word／PDF様式を新たに実装したものではない。

例の資料は全国網羅、現在の計画の網羅、法的承認確認、自動更新可能性を保証しない。実例の再生成にはローカル保存原本が必要で、Git cloneだけで原本を同梱取得できる設計ではない。各国担当は公式情報源の再確認と国別アダプターの作成を続ける。

今回の納品はPrivateテンプレートのコード・仕様・検証記録。DDPT本体、ウガンダ版、他国リポジトリおよび公開サイトは変更していない。共通UX全体のv1.0採用完了とは区別する。
