# 実行テンプレート0.8.2 検証記録

検証日: 2026-09-15 JST。環境: Windows、Node.js、Codex in-app browser。

対象: AreaDataの公開向け見出し・紹介文。前版: `c2f7e99`。

## 変更と目的

- 「世界から、あなたの地域へ。」を主見出しにし、国勢調査を国から県・市町村へたどり、人口や暮らしを比較して研究・計画に利用する目的を説明する。
- 「中米7か国パイロット」「不足もすべて見える」を入口の主見出しから外し、現在の収録範囲は「中米7か国」と表示する。実データの国名・ID・記録は保持する。
- 重複する導入見出しを整理し、紹介文・収録範囲・探索ボタンから地図と国一覧へ進める構成にした。国一覧の表示は1国1行。
- 集計方針は出典欄の「地域の合計値の算出方法」へ移し、各数値の基準年、欠測、出典、算出根拠の表示を保持する。
- トップの説明、機能カード、ブランド説明、フッターを英語・スペイン語・日本語で揃える。READMEに公開文章の方針を記載する。
- 翻訳辞書などの内部moduleも生成時の版付きURLで読み込む。入口moduleだけが更新され、古い翻訳が使われるキャッシュ混在を防ぐ。
