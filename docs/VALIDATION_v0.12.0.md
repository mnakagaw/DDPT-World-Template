## 採用と出典

国際系列は20→27指標。追加はUNSD国民経済計算のGDP総額・1人当たりGDP・2020年固定価格GDP、国連SDG配布のILO失業率・若年NEET率とUNODC故意の殺人率、IMF WEOの年平均消費者物価上昇率。原本URL、取得時刻、容量、SHA-256は各sourceレコードに保存した。UNSDの3原本はSHA-256 `fd8a19a7…`、`5fcbf3ed…`、`352c7057…`、IMF原本は`b29239cb…`、SDG原本は`5aad401a…`である。原本の全ハッシュは正規化データの`source_files`に残し、Gitや公開サイトへ大容量原本を複製していない。

新しいdatasetは20,773地域・27国際指標を含む全686指標・282,115観測。前版の268,870観測はキー・内容とも全件一致し、新規13,245観測だけを追加した。世界の2024年GDP総額は111,565,144,064,828.95 USドル、1人当たりGDPは13,673.101 USドル、IMF公表の世界インフレ率は5.792%。アメリカ大陸の同年GDP総額は38,791,026,261,693.42 USドル、1人当たりGDPは37,029.451 USドルで、いずれも元表の公表地域行である。IMFのグループはUN M49と一致させず、アメリカ大陸のインフレ率の代表値は作らない。

`npm run check`は成功、`npm test`は205件成功・失敗0。dataset検証はエラー0・警告0。日本語の地域診断で、アメリカ大陸の1人当たりGDPは46／57地域の最小Haiti、最大Bermuda、差134,615.79 USドル／人を表示した。インフレ率は地域全体の未公表を小さく案内し、36／57地域の最小Saint Lucia、最大Argentina、差220.56ポイントを表示した。端数で表示値の差と異なる場合は丸め前の元値から計算した旨を表示する。故意の殺人率も28／57地域の比較を表示した。世界のインフレ率はIMF公表の世界値を表示する。対象・指標・年・出典を含むURLの読込でアプリエラーはなかった。
