## ブラウザーで操作した範囲

EdgeでローカルHTTP配信のウガンダ生成サイトを操作した。

- 地域診断 → Eastern Region → テーマ診断 → 電力指標 → 2020年 → 地図でCentral Region → 計画資料の移動で、地域・指標・年を維持。
- 再読込・戻る・全国への復帰で対象と比較条件を維持。
- 地方観測0件のとき、全国値を別表示し、地方値・中央値・順位を作らない。
- 初期指標が取得失敗でも、未指定時には取得済み指標と数値のある期間で開始する。利用者が明示した欠測期間は維持する。
- 編集用Markdown、CSV、印刷用HTMLの3ファイルを実際にダウンロード。Central Region・2020年・未承認の汎用資料という表示を確認。CSV12行の地域・期間・欠測・出典列を確認。
- 通常のデスクトップ幅、375px・320pxの幅で表示を確認。確認したホーム・テーマ診断で文書全体の横はみ出しなし。テーマ地図・操作部を目視確認。
- 確認した操作中のブラウザー警告・エラーログは0件。

ルワンダでもホーム・地域診断を表示し、全国人口等の取得値、5参照地域の選択肢、2025年の初期選択を確認した。
