# Saudi GASTAT detailed-age table: source location only

Checked 2026-09-26 on the [official GASTAT Tableau view](https://tableau.stats.gov.sa/views/TA3-PopulationbydetailedAgebyRegionGovernorateNationalityandGender_17298115570530/NW-PopulationbydetailedAgebyRegionGovernorateNationalityandGender). The public view is titled **Population by Detailed Age**. Its controls show `Region`, `Governorate`, `Gender`, `5 Year Age Groups` and `Absolute` display. The metadata panel identifies code `TTCENPOP0105`, producer General Authority for Statistics, and a population definition with detailed age, region, nationality and gender breakdowns. It describes a ten-year frequency. The inspected panel did **not** establish the observation period or the full row inventory.

The view's **Export as Excel** control opened a crosstab download dialog with `Z - Full Data` selected. Clicking its download action did not yield a verifiable file in this browser environment; the download event timed out and no matching recent XLSX/CSV file was found locally. A response from an attempted public CSV view contained no table rows. These are acquisition failures for this check, not proof that GASTAT provides no export.

The source is registered in the isolated Saudi `r2` candidate with status `not_collected`. No age, gender, nationality, governorate or other value from the view was adopted. In particular, the GASTAT view's period has **not** been equated with the Ministry of Health yearbook's 2022 census column. The previously adopted 2022 country and 13 administrative-region values remain attributed to [MOH Table 1-12](https://www.moh.gov.sa/en/Ministry/Statistics/book/Documents/Statistical-Yearbook-2022.pdf), which cites GASTAT. The 2017 reference shapes are still matched by names only.

Next: acquire a complete official export or publication and its metadata; audit every table field, period, population and denominator; reconcile official administrative codes and the census-date boundary version; decide adoption only after those checks. The Kit feedback is a public URL lead at `official_location_identified`, requiring independent acquisition and audit.
