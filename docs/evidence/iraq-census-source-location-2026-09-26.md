# Iraq 2024 census source location and local acquisition

Checked 2026-09-26. The [official National Open Government Portal dataset](https://nogp.gov.iq/DatasetDetails.aspx?id=17) identifies the publisher as Iraq's Commission of Statistics and GIS (COSIT) and lists `تعداد 2024.xlsx` as the final 2024 population and housing census results. The [portal's API metadata](https://nogp.gov.iq/api/v1/datasets/17) identifies resource 23 and states a CC BY 4.0 portal license. The direct API file endpoint returned `INTERNAL_ERROR`; an ASP.NET download postback from the public dataset page returned the 13,294-byte workbook. SHA-256: `2f2446396744ec8c760b797d46b2b177ec8954aa2ef8542c5c319f9b608176f9`. The file and receipt are retained only in the ignored local `generated/iraq-areadata-20260926/raw/` directory pending resource-specific terms review.

The workbook has 18 governorate rows and one national row, with original tabulated population, Cabinet-decision-adjusted population, foreigners, adjusted Iraqi population and governorate share as distinct columns. All four additive governorate columns reconcile to the national row; both national population columns read 46,118,793. The adjusted Iraqi total is 45,778,662. AreaData imported the five columns separately and retained exact cell references. The adjusted column must not silently replace the original one.

The [official COSIT 2024 census report catalogue](https://cosit.gov.iq/ar/1234-2019-09-05-07-53-20) also supplies a 562-page PDF. It was acquired locally but its detailed tables, codes, definitions and reuse terms have **not** been fully audited. The 18 governorate source labels have a manually checked name correspondence with 18 geoBoundaries 2022 reference shapes; no official code or certified 2024 boundary match is claimed. No district values or planning documents are adopted.
