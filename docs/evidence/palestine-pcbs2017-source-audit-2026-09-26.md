The adopted updated-summary national value is **4,781,248** at the 30 November–1 December 2017 census reference. It includes **75,393** post-enumeration estimate residents beyond the separately reported counted population. West Bank **2,881,957** plus Gaza Strip **1,899,291** matches the national published value. All 16 governorate source rows match their respective region total; all 585 locality rows have women + men = total. Fifteen governorates' locality values sum to their directly published governorate value. Jerusalem is different: J1 **281,163** is aggregate-only in Table 29; J2 **154,590** has 29 coded locality rows that exactly sum to J2. J1 + J2 = the governorate's **435,753**. The importer preserves those two reporting zones and never claims J1 locality detail. None of these historical counts is current population; WDI national midyear population remains a separate international indicator and is not allocated to localities.

The candidate has **606 territories** (national + two regions + 16 governorates + two Jerusalem zones + 585 localities), **four census indicators** and **1,837 direct source observations**. Three population/sex values exist at each territory; the household count is available only at the 19 Table 2 parent rows. Source page, row and column locators are stored per observation. Names broken across PDF lines were rejoined; code digits and stray punctuation from the Arabic column were removed. The importer rejects changes in expected pages, all parent totals, sex sums, unique code count, locality-to-parent totals and the code-guide discrepancy list. Repeated names retain separate PCBS codes.
