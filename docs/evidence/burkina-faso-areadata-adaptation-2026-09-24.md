# Burkina Faso country edition — evidence and limits, 2026-09-24

This is a **local AreaData review build**, not a published or independently accepted country edition. The generated project is `generated/burkina-faso-20260924/` and is ignored by the template repository. The reusable importer is in `scripts/country-burkina-faso/`. The canonical dataset, raw receipts, source inventories, site, and validation record remain in the local project. A template-code Git commit does **not** contain the country's data or certify public release.

## Current local build

The dataset has **410 territories** (country + 13 regions + 45 provinces + 351 communes), **64 indicators**, **15,984 observations**, **27 source records**, and **4 national planning references**. Dataset SHA-256: `53d17c6d10f60cdea5fcb8c317e43e37123c680a37d9af386875f9eb0715baa2`. Census age-sex pyramids cover the country and 13 regions, with every five-year band checked against its male, female, and total rows. There is no inferred province or commune pyramid. The country and region-level latest values can have different source years; the interface shows the year with each value. Changing a thematic metric also selects that metric's latest available source year instead of retaining an invalid year and showing false “no data.”

The INSD 2019 geography is historical. The [Presidency's 2025 reform notice](https://www.presidencedufaso.bf/conseil-des-ministres-du-2-juillet-2025/) describes 17 regions and 47 provinces. The review build keeps the historical 13/45/351 records and does not assert a legal crosswalk to current authorities. ADM1 and ADM2 polygons are [geoBoundaries reference geometry](https://www.geoboundaries.org/), with verified name matches for the 2019 dataset; no verified joined commune polygon is available. The UI must show that gap without substituting a neighboring polygon.

## Acceptance boundary

Local schema validation and selected browser flows have been run; see the project's `evidence/validation.json`, `evidence/ACCEPTANCE.md`, and `evidence/COUNTRY_LESSON_AUDIT.md` for exact scope. **Full 42-scenario acceptance, all-source numeric-column audit, current consolidated planning law, local plan/budget collection, independent audit and public-site verification remain open.** Only selected 2025 legal articles were reviewed. The website's planning outputs remain Markdown, HTML, evidence CSV and document CSV. The newly requested country-specific [Word diagnostic](burkina-faso-word-qa-2026-09-24.md) is generated and visually reviewed from the dataset but is **not yet a live selected-area site download**. Official procurement notices for Komsilga and Banfora are leads for plan preparation, not acquired approved plans or budgets; further official [fiscal and planning leads](burkina-faso-fiscal-planning-leads-2026-09-24.md) remain unadopted. No BFA hosting destination was assigned. This build must not be represented as a fully accepted national edition. The twelve source leads returned to Census Dashboard Kit have the conservative stage `official_location_identified`, even where the local project acquired a PDF, so a new Kit project must repeat URL, terms, content and geography checks.

The [42-scenario acceptance ledger](burkina-faso-acceptance-42-2026-09-24.md) records each scenario separately: 0 passed, 39 not fully executed and 3 out of scope. Partial code, output and browser checks are evidence, not acceptance. No independent auditor has reviewed the BFA edition.

A separate ignored project, `generated/burkina-faso-replay-20260924/`, was rebuilt from the generator output and locally cached raw PDFs/GeoJSON using the tracked adapter sequence. It reproduced all 410 territories, 64 indicators, 15,984 observations, 27 sources and four documents; the observed `(territory, indicator, period, value)` set, planning configuration and 14 age-sex profiles matched the review build. `npm run check` and all 213 tests passed, country validation returned zero errors and 13 source-terms warnings, and four-level generated Markdown/HTML/CSV content checks passed. This checks reconstruction from acquired inputs, not whether the unreviewed source tables or legal obligations have been completed. National HTML output is approximately 9.7 MB, so actual browser printing and load performance remain acceptance risks.
