# Burkina Faso country edition — evidence and limits, 2026-09-24

This is a **local AreaData review build**, not a published or independently accepted country edition. The generated project is `generated/burkina-faso-20260924/` and is ignored by the template repository. The reusable importer is in `scripts/country-burkina-faso/`. The canonical dataset, raw receipts, source inventories, site, and validation record remain in the local project. A template-code Git commit does **not** contain the country's data or certify public release.

## Current local build

The dataset has **410 territories** (country + 13 regions + 45 provinces + 351 communes), **57 indicators**, **15,886 observations**, **23 source records**, and **4 national planning references**. Census age-sex pyramids cover the country and 13 regions, with every five-year band checked against its male, female, and total rows. There is no inferred province or commune pyramid. The country and region-level latest values can have different source years; the interface shows the year with each value. Changing a thematic metric also selects that metric's latest available source year instead of retaining an invalid year and showing false “no data.”

The INSD 2019 geography is historical. The [Presidency's 2025 reform notice](https://www.presidencedufaso.bf/conseil-des-ministres-du-2-juillet-2025/) describes 17 regions and 47 provinces. The review build keeps the historical 13/45/351 records and does not assert a legal crosswalk to current authorities. ADM1 and ADM2 polygons are [geoBoundaries reference geometry](https://www.geoboundaries.org/), with verified name matches for the 2019 dataset; no verified joined commune polygon is available. The UI must show that gap without substituting a neighboring polygon.

## Acceptance boundary

Local schema validation and selected browser flows have been run; see the project's `evidence/validation.json`, `evidence/ACCEPTANCE.md`, and `evidence/COUNTRY_LESSON_AUDIT.md` for exact scope. **Full 42-scenario acceptance, all-source numeric-column audit, current planning-law article analysis, local plan/budget collection, Word output, independent audit, FTP deployment, and public-site verification remain open.** This build must not be represented as a fully accepted national edition. The eight source leads returned to Census Dashboard Kit have the conservative stage `official_location_identified`, even where the local project acquired a PDF, so a new Kit project must repeat URL, terms, content, and geography checks.

A separate ignored project, `generated/burkina-faso-replay-20260924/`, was rebuilt from the generator output and locally cached raw PDFs/GeoJSON using the tracked adapter sequence. It reproduced all 410 territories, 57 indicators, 15,886 observations, 23 sources and four documents; the observed `(territory, indicator, period, value)` set and 14 age-sex profiles matched the review build exactly. This checks reconstruction from acquired inputs, not whether the unreviewed source tables or legal obligations have been completed.
