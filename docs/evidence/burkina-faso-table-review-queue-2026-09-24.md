# Burkina Faso RGPH table-review queue

The acquired 2019 INSD statistical-tables PDF has 581 inventoried table headings. Fifteen selected tables already have adopted values, ten additional tables have printed-page decisions without new adoption, and 556 still require a printed-page/semantic decision. The ignored local project contains `evidence/TABLE_REVIEW_QUEUE.csv` and `TABLE_REVIEW_QUEUE_SUMMARY.json`, generated by `scripts/country-burkina-faso/build-census-review-queue.py` after `screen-statistical-tables.py`. The queue does **not** adopt a value or change the dashboard.

| Queue group | Pending tables | Meaning |
| --- | ---: | --- |
| All 13 historical region names detected | 109 | Inspect first because a regional comparison may be available. A match does not establish compatible columns or denominator. |
| Some historical region names detected | 35 | Inspect next; a table may intentionally cover a subset, continue onto another page, or have an extraction error. |
| No historical region name detected | 412 | Inspect after the first groups. **Do not call these national-only:** labels may be codes, different spellings, cities, provinces, or unreadable text. |

Across all 581 headings, at least one of the 13 historical region names is detected in 163 table bodies, and all 13 in 124. These are text-detection counts, not counts of adopted comparable regional datasets. Five hundred eighty tables have at least one numeric candidate line under the automated rule; a non-match in the remaining table is not proof of no numerical information. The 3,900 candidate numeric **positions** are not verified semantic columns.

The screen script now uses the first actual body-table page (physical PDF page 27) as the lower bound for heading detection. A line-number threshold alone had misidentified late table-of-contents headings on physical page 22 as body tables, producing wrong `first_pdf_page` entries. After the correction, the 581 headings, 3,900 candidate positions and region-name counts stayed the same; the erroneous early page locators were removed. The first pending regional queue entry is I.22 on physical page 42, not a chapter-XII table on the contents page.

For each queue row, open the indicated physical PDF page **and any continuation pages**, then record the complete printed title and column hierarchy, unit, reference year, geographic code/name and edition, population/denominator, footnotes, missing-value symbols, and method. Compare any proposed row with an already-adopted value and its source; decide `adopt`, `cross-check only`, `defer`, `incompatible`, or `out of scope` with a reason and exact page/column locator. Treat `NA`, `NC`, blank, zero and acquisition failure separately. Write accepted columns to a source-specific audit before changing observations. The row's absence of a region-name hit is never a data-absence disposition.

The source PDF is local and not committed. The screen, queue, printed-page decisions and numeric cross-check can be rebuilt in order from the adapter [README](../../scripts/country-burkina-faso/README.md). Reviewers should use the ignored PDF SHA-256 `a665f61e49581cb39e85fdd3d70cb699acf3ec7b964dfbb2852fd35cfc19d7f2` to ensure the same source edition.
