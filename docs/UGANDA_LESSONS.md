## 共通仕様と国別仕様の境界

| 共通仕様として保持するもの | 国別の証拠と業務に応じて設定するもの |
|---|---|
| 地域から把握する地域診断、指標から比較するテーマ診断、地域から資料へ進む計画資料の目的 | 採用するモジュール、正式名称、言語、計画制度・章立て・担当組織 |
| ページ間の地域・指標・条件継承、選択対象と表示内容の一致 | 行政・統計階層の数と意味、自治体型、公式コード、境界版 |
| 出典・期間・単位・比較対象の表示、欠測・ゼロ・対象外の区別 | 指標、取得頻度、集計可能性、分子分母、比較できる期間・地域集合 |
| 資料の収録状況と制度上の承認状態を区別する | 現地で確認した資料状態・審議状態・承認制度の定義と根拠 |
| 統計上の分類と事業の支援対象を区別する | 支援対象の公式な集合、適用時期、参加を裏付ける資料 |
| 共有URL、戻る・進む、再読込、保存互換、取得物の対象確認 | 公開方式、認証、保存先、移行契約、現地の帳票形式 |

「3ページ・29指標・2024年・146自治体・4階層・12対象県・8章」はウガンダ側の仕様であり、世界共通の固定値にしない。DDPTの機能範囲をウガンダの3ページへ一律に縮約しない。
ドミニカ共和国のEND、CDM、OMPP、SISMAPや承認区分は、画面構成に似せるために他国へ持ち込まない。[制度制約45行](https://github.com/mnakagaw/Uganda-LGDP/blob/acfffadab3df63ccea0d41f4c1692b7f1a09f9ad/docs/ddpt-page-alignment.md#L45)

## データ能力に応じた表示の分岐

| 得られる証拠 | 選べる表示・取得 | 避ける処理 |
|---|---|---|
| 正確な年齢別・男女別実数 | 数値図、定義した割合、出典付き数値CSV | 定義・階級の異なる年次をそのまま重ねる |
| 公表された図だけ | 原図、地域名・年・原典頁、原図PNG | 棒の長さを正確な人数としてCSVへ変換する |
| 全国値だけ | 全国と明示した参考表示 | 地方図に代用する、人口比で地方値を補う |
| 分母のない公表率 | 原典の地域率、集計不可の表示 | 地域率の単純平均、無根拠な加重平均 |
| 統計はあるが境界がない | 一覧・検索・表と境界未取得の表示 | 同名・近隣の境界を借用する |
| 境界はあるが統計との結合が未確認 | 灰色の欠測表示と出典ID | 近隣統計の流用、ゼロ置換 |

ウガンダではAdjumaniとMukonoの2024年原図を取得した一方、正確な地方別5歳階級男女実数は未取得。原図は18階級・最終85歳以上、全国数値表は20階級・最終95歳以上で、同じデータ能力として扱わない。[原図の制約95行](https://github.com/mnakagaw/Uganda-LGDP/blob/acfffadab3df63ccea0d41f4c1692b7f1a09f9ad/docs/ddpt-alignment-2026-09-13.md#L95)

## 共通回帰試験へ移すシナリオ

以下は既存の試験コード・記録から抽出した次回用の受入シナリオであり、世界版の合格記録ではない。

1. 地域A→地域B→同名の別行政型→全国で、地図・基本値・図・資料対象が一致し、分析中の指標を保持する。
2. 別の保存済み指標を持つ地域を選んでも分析中の指標を保持し、その地域の計画メモを失わない。
3. 初期表示範囲外の地域を名前・公式コードで検索でき、比較母集団と中央値が検索前後で変わらない。ウガンダの具体例は水指標で13位のAdjumani、コード301。
4. 真の0、観測欠測、分母不足、統計未結合の境界、境界未結合の統計を別々に確認する。
5. 全国観測と地方合計の差を説明し、未配属分を架空自治体・近隣の境界に割り当てない。ウガンダのAPAAをケースにする。
6. 行政・統計分類と支援対象が交差しても所属を混同しない。West Nile統計小地域と12県の事業対象をケースにする。
7. 資料未取得を「計画が存在しない」「未承認」と表示しない。取得資料の件数と資料を持つ自治体数を分ける。
8. 原図のある地域→全国→原図欠測地域で以前の図が残らない。Adjumani→All Uganda→Arua Cityをケースにする。
9. 読込中・失敗中・地域切替中に前の地域の文書を取得できない。Arua DistrictとArua Cityの財政資料を混ぜない。
10. 直リンク、旧リンク、共有、再読込、戻る・進む、保存・復元で同じ地域・指標へ戻る。
11. 狭幅・中幅・通常幅、実際の200%文字拡大、キーボードで主要タスクを完了する。
12. 実際に取得したWord/PDF/PNG/CSVの地域・年・単位・出典・欠測を確認する。取得成功だけで合格にしない。
