# 国名だけを受け取ったAIの国別作業手順

この手順は、新しい案件でDDPT-World-Templateを参照し、その国の公開資料を取得して動作するサイトを作るためのもの。利用者の国名は作業開始に十分な入力として扱い、AIが開始シートを埋める。長い質問票を返して作業を止めない。

国別出力のルートへコピーされたこの文書を読む場合、`scripts/`・`templates/`と補助資料への参照は、記録したテンプレートclone内で解決する。`HANDOFF.md`にその絶対パス・GitHub URL・参照commitを残す。見つからなければ同じcommitのリポジトリを読み直し、国別データを初期化しない。

## 1. 既存の依頼と作業場所を確認する

- 既存の国、言語、利用目的、保存先、公開依頼、利用可能な資料・資産を優先する。
- テンプレートの認証済みcloneと参照commit、対象案件の既存ファイル・変更を確認する。テンプレート、DDPT、他国の作業中成果を国別出力先にしない。
- 新規出力先が未指定なら、案件ワークスペース内の未使用ディレクトリを選ぶ。`create-country.mjs`は新規作成用で、再開時の上書き手段ではない。
- 国名は原入力を残してISO国IDへ正規化する。同名・通称が複数の国を指し、選択によって資料や制度が変わる場合だけ短く確認する。

AIが`templates/COUNTRY_START.md`を案件へコピーして記入する。初期の既定値は次のとおりで、調査結果により更新する。

| 未指定項目 | 作業を進める既定値 |
|---|---|
| 利用目的 | 地方の計画担当者による地域診断と資料取得、中央・広域担当者による地域比較 |
| 納品範囲 | ローカルサイト・データ・採用出力・検証記録。別リポジトリ作成や外部公開は現在の依頼範囲に従う |
| 画面言語 | 取得した公式資料と利用者指示を確認して暫定設定。CLIの初期localeを現地要件確認済みと扱わない |
| 地理粒度 | 公式の行政・統計区分を調べ、値と地域対応を検証できる粒度から提供 |
| 時点 | 指標ごとに取得可能な期間を明示。同年比較が成立する集合を使い、分野間の年の違いは表示 |
| 機能 | 地域診断・テーマ比較・計画資料への経路を中心に、投資・要求・文章生成・保存・出力を根拠に応じて採用 |
| 更新・運用担当 | 未定と記録。勝手に担当者、通知先、更新頻度を確約しない |

## 2. 初期収集を実行する

テンプレートのルートから実行する。出力パスと国名は実案件へ置き換える。

```sh
node scripts/create-country.mjs --country "ウガンダ" --out ../uganda-dashboard
```

生成された`data/dashboard.json`、`raw/`、検証結果、`gaps`を読む。WDI全国値とgeoBoundaries ADM1の取得可否を確認し、取得失敗を欠測ゼロや未公開に読み替えない。国の正規化に失敗した場合は公式名称・ISO IDを調べて入力を直し、取得障害なら原因を記録して取得可能な別資料の作業へ進む。

**この工程は初期生成であり、完了地点ではない。直ちに次の公式資料調査へ進む。**

## 3. 国内の公式資料を調べて取得する

次の分野を並行して調べ、取得・統合は依存関係に沿って進める。現地語と英語の名称も使う。機関名、現行制度、リンク、資料の時点はその案件で確認する。

| 分野 | 最初に確認する一次資料 | 残す成果 |
|---|---|---|
| 地域・コード | 統計局／国勢調査の地域コード表、行政機関の区分・境界・改編資料 | 地域台帳、版、有効期間、コード対応表、未結合一覧 |
| 地方統計 | 国勢調査、公式統計ポータル、地域別統計書、行政統計 | 人口・サービス・生計等の取得可能な地方値、定義、年、分子分母、出典箇所 |
| 計画制度・資料 | 国・地方の計画機関、法定手引き、地方計画、公式様式 | 対象階層、計画期間、担当主体、資料リンク・原本、取得状態、承認根拠の別記録 |
| 予算・公共投資 | 財務機関、公開予算書、地方財政、事業台帳 | 期間・金額単位・予算／実績・事業ID・対象地域と重複方針 |
| 住民要求・参加 | 公開された協議記録、提案台帳、制度手引き | 出典付きの要求・参加・決定の区別。未公開なら理由と代替作業 |

公開データがAPIや表で提供されるなら、その取得方法を優先する。公式Excel・PDF・原図しかない場合も、利用可能な表計算・PDF・文書のツールと該当スキルで抽出し、元の表・ページと照合する。内容を取得できないリンクを「本文確認済み」と記録しない。

同じ指標・期間・定義・地理範囲で比較できる国内公式値がある場合は、国内の一次資料を優先する。国際データの方が新しい等の差は隠さず、別出典・別系列として保持して採用理由を記す。国内地方値とWDI全国値を定義照合なしに足し合わせない。

公開されていて取得できる優先資料は実際に取得し、[SOURCE_ADAPTER_GUIDE.md](SOURCE_ADAPTER_GUIDE.md)に従ってアダプターを追加する。資料の候補リンクを列挙しただけで国別収集を完了にしない。

## 4. 地方データを統合し、機能を適応する

1. 地域の名前より先に、コード体系・公式コードの根拠・境界版・親子関係を照合する。geoBoundariesのshapeIDはprovider IDとして扱う。
2. 同名地域、独立市、境界改編、複数地域事業を検査し、曖昧な結合は未結合として残す。
3. アダプターで`schema_version: "0.2"`へ正規化し、出典・原本hash・抽出位置・変換方法を保存する。
4. 既存データと統合する際はIDと観測キーの重複、期間、単位、地域数、カバー率を確認する。全国値を地方へ補完しない。
5. `実装／条件付き実装／代替／保留`を指標・地域・期間・境界版ごとに決める。地図なしなら一覧、時系列なしなら実在する時点、根拠不足なら資料と補完欄を提供する。
6. DDPTの二つの診断入口、選択地域の連動、出典と欠測、計画資料への到達を保つ。粒度差を理由に首都へ戻したり、別の追加操作を必須にしたりしない。

地方値・資料がないと判断する前に、公式ポータル、国勢調査表、地域統計書、計画／予算資料の確認結果を残す。「初期アダプターが未対応」は「資料が存在しない」ではない。

## 5. 再構築して実物を検証する

```sh
node scripts/build-country.mjs --project ../uganda-dashboard
node scripts/serve.mjs --dir ../uganda-dashboard/site --port 4173
```

ブラウザで`http://127.0.0.1:4173`を開き、データ契約の検証と画面・取得物の実操作を分けて記録する。検証エラーは修正し、警告は理由・影響・処置を判断する。

- データが比較的揃う地域と不足する地域で、選択→診断／比較→計画資料→採用出力を確認する。
- 全国・同名地域・異なる行政型・未対応粒度、URL共有・再読込・戻る、絞り込み範囲を確認する。
- 出力を実際に取得し、地域・期間・単位・代表値・出典・草案状態を画面と照合する。利用可能な形式のみを対象にする。
- 狭い画面、文字拡大、キーボード、待機・失敗・再試行を[受入記録](../templates/ACCEPTANCE.md)に沿って確認する。
- 現地担当者による利用確認はAIのブラウザ試験と別に扱い、未実施なら残す。

## 6. 欠測台帳と再開点を保存する

次はAIが案件側へ作成・更新する記録で、CLIが自動作成済みと想定しない。生成器が同目的の資料を作る場合はその名称と場所を確認して再利用する。

| 記録 | 最低限の内容 |
|---|---|
| `evidence/SOURCES.md` | 実際に確認した機関・資料URL・時点・取得結果・選定理由・原本・アダプター・再実行方法 |
| `evidence/CODE_CROSSWALK.csv` | provider ID、公式コード、コード体系、境界版、対応根拠、照合状態。未照合は空欄の意味を明記 |
| `evidence/GAPS.md` | 分野・地域・期間、不足の種類、確認済み資料、試した取得方法、障害、次の具体的行動、担当／再確認条件 |
| `evidence/ACCEPTANCE.md` | 対象版、実データ、環境、各試験、証拠、合否、未実施 |
| `HANDOFF.md` | 完了工程、途中工程、各記録のパス、最後に成功したコマンド、次のコマンド、未解決事項、依頼済みの範囲 |

コンテキスト切替や中断前は`HANDOFF.md`へ作業途中の資料URL・原本・抽出位置・失敗内容も残す。再開時はその記録と現物を確認し、初期収集をやり直して公式地方データを消さない。

## 7. 完了を判断して報告する

初期生成だけで終了しない。優先する国内公式資料を調べ、取得可能な地方統計と計画資料を取り込み、地域作業と採用出力を実装・検証してから成果を報告する。全指標の網羅収集を約束する必要はないが、採用範囲・収録率・未収録範囲が説明できなければならない。

必要な資料が公開されていない、アクセス権がない等の制約は、確認した根拠と代替機能、未完了の業務を明示する。制約下で提供できるローカル版を作成し、全国参考データと境界のみの状態を「地方計画版完成」と呼ばない。

現在の依頼にGitHub作成・公開まで含まれる場合は、その範囲の版・配備・公開後確認まで進める。国名だけで始めた案件ではローカル成果を既定とし、テンプレート本体のPrivate GitHub作成許可を別国リポジトリや公開サイトへの許可へ転用しない。
