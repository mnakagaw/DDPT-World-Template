# Census Dashboard Kitの国別制作からAreaDataへ移す知見

調査日：2026-09-17

## 調査対象と事実範囲

次の実物を照合した。

- Codexタスク `codex://threads/01a0a2b1-7628-74d1-94ca-1c0d8b67066d` の国別制作・修正・公開記録
- Publicリポジトリ [mnakagaw/Census-Dashboard-Kit](https://github.com/mnakagaw/Census-Dashboard-Kit) の国別制作基準 commit `88de64677d2691fa8ec83acbf71449943ac04374` と独立監査工程 commit `3f8861637d60481c09f5f2da1ca5f4c33b3082c0`
- ラオス成果 `★20260915CensusDashboardKIT/lao` と公開版 <https://icnet.tokyo/census/lao/>
- バングラデシュ成果 `★20260915CensusDashboardKIT/bgd` と公開版 <https://icnet.tokyo/census/bgd/>
- フィリピン成果 `★Antigravity/CensusDashBoard/philippines` と独立レビュー `evidence/CODEX_INDEPENDENT_REVIEW_2026-09-17.md`

指定タスク内で完成・公開まで確認できた新規国別成果はラオスとバングラデシュの2件だった。その後、別AIが作成したフィリピン版へ独立監査を適用し、自動検証の合格と意味・操作・実出力の完成が一致しない事例を確認した。ドミニカ共和国とウガンダは設計上の参照事例であり、このタスクで新規作成した国として数えない。

本書では、会話上の要求、Kitに実装済みの共通機能、国別成果の証拠、AreaDataへの採用判断を分ける。Publicリポジトリの緑のActions、初期生成の成功、公開先の表示だけを国別版完成の証拠にはしない。

ラオスの初期試作は、取得済みの原列を捨て、全国値を地方画面へ並べ、ADM2境界がないまま大きな空地図を出し、Census PDFを計画法として扱う等の問題を含んだ。後続修正で、原表棚卸し、階層別比較、全件欠測、地図範囲、URL復元、Word内容を再検証した。バングラデシュでは、代表1県の資料だけで完了せず、公式64県目録の全資料を取得・hash・統合した。この差から、完成は「ページ生成」ではなく「対象範囲を閉じる工程」と分かる。

## フィリピン独立監査で増えた教訓

フィリピン版は、国別validatorのerror・warning 0、delivery gateの `ready: true`、自動試験138件合格、106地域・21指標・1,756観測という自己申告上の完成条件を満たしていた。しかし、別の監査担当が原資料、正規化データ、画面、操作、取得文書を照合すると、公開を止めるべき問題が残っていた。

| 発見 | 問題の性質 | AreaDataへ追加する検査 |
|---|---|---|
| 5つの保健指標で、元変数の意味と表示ラベルが不一致 | source IDや数値型だけでは意味を検証できない | 元表のfield・定義・母集団・単位とindicator定義の対応を人と機械の両方で確認する |
| 1993～2003年の全国値と2022年の地方値を同じ `latest` 表示に混在 | 最新判定を登録文字列へ依存していた | 指標×地域×系列ごとの最大確認年を観測から再計算し、異なる粒度の年を混ぜて最新と呼ばない |
| 算出率を `Source reported` と表示し、式・構成値がない | provenanceの自己申告が実処理と一致しない | reported／calculatedを原観測と変換履歴から判定し、算出値には式・分子分母・被覆を必須にする |
| 2020年の17地域境界を現行として使い、2024年の18地域構成と不一致 | 境界・行政区分の有効時点を確認していない | 地域台帳の件数・型・有効期間を最新公式資料と照合し、旧版は旧版として表示する |
| 選択したRegion内ではなく全国88地域をテーマ比較 | 地域選択と比較集合の契約違反 | 選択親のchildren集合と地図・順位・中央値・表・CSVのID集合を再計算して一致させる |
| 法令・手引きが境界sourceへ誤接続し、期間も創作 | リンクの存在だけを内容確認と扱った | source種別、発行者、本文、対象制度、期間を原資料で確認し、境界・統計・法令を別役割にする |
| 年齢・性別資料があるのに人口ピラミッドを不採用・理由なし | 取得済み列の棚卸しが機能判断へつながっていない | 発見した有用な原表について採用、代替、非採用と理由を閉じる |
| 13ページWordが指示文・空欄中心で、図表・実質診断がない | ファイル生成と内容完成を同一視した | 全ページrenderだけでなく、地域・値・図表・引用・診断本文の存在と画面との一致を検査する |
| `No gaps`、汎用ラベル、日英混在、曖昧な全体選択 | UI文言と不足台帳を実データから検証していない | 不足件数、対象地域型、翻訳状態、操作後の対象を実データ・ブラウザ挙動から確認する |

自動gateは有効だが、自己申告されたboolean、ファイルの存在、件数、リンクの存在だけを集めると誤った完成判定を強化する。gateは可能な範囲で元データと生成物から意味・最大年・比較集合・算出根拠・文書内容を導出し、独立監査はその計算自体を再確認する。

国別サイトの既定入口についても整理した。通常は全国のTerritorial Diagnosticを `/` とし、汎用landing pageを別に置かない。国別事情で独立したhomeを追加する場合だけ、出典付き基本情報、全国人口と年、登録済み行政階層、3ページへの明確な経路を置き、効果や次の操作が分からないselectorを置かない。

## ウガンダ・バングラデシュ・ラオス再監査で増えた教訓

同じ独立監査を3案件へ適用した結果、3件とも `REJECT` となった。これは3件のデータ全体が不正という意味ではない。実データと地理がよく照合できた案件でも、完成・公開を止める個別の契約違反が残ることを示す。

| 案件 | 自動検証・確認できた長所 | 独立監査で残った主な問題 | 追加する規則 |
|---|---|---|---|
| バングラデシュ | 現行Kit 154/154合格、country validator error 0、64 workbookの存在 | division selectorがURLと選択肢だけChattogramへ変え、本文はDhakaのまま。64冊の18～20 sheetに対し、台帳は汎用1表とcatch-allで `all_tables_checked: true`。District文書をUnion Parishad規則中心で構成 | 選択完了はURLではなく全表示・downloadの同一IDで判定。全表確認フラグは実sheet・field台帳から算出し、catch-allで閉じない。計画主体と適用法令を同じ行政型で照合 |
| ラオス | 現行Kit 154/154合格、validator error/warning 0、167地域・42指標・1,896観測、166/166境界結合、代表値一致 | OPHI 6 sheetとCOD-PS多数列を個別に採否記録せずcatch-all。英語画面の42指標がすべて日英併記。現行地方計画manual未確認のままplanning completed。Wordに単語途中改行と全国値の `Not collected` 表現 | 列台帳をsource固有のfield単位で閉じる。翻訳は表示言語別文字列で検査。一般法だけで地方計画様式完成としない。地方欠測と全国context有りを分ける |
| ウガンダ | 15表78数値列、68指標、代表値・算出率・難民数・APAA・地理を独立照合 | READMEの `npm run dev` がpublic JSON直接importで空白。現行68指標に対し集計testの期待件数が旧754のままで実測1,768、1件失敗。Wordに注記だけの空き頁 | 公開済みdistだけでなく記載された再現手順を試す。検査件数はデータから導出し、拡充後に固定件数を更新。文書は内容だけでなく改頁・孤立注記も確認 |

3件から、独立監査の目的は既存テストをもう一度走らせることではなく、**テストが検査していない前提を見つけること**と分かる。特に次を共通gate候補にする。

- `all_tables_checked` と `all_numeric_fields_decided` は、原本のsheet／table／field集合と台帳の一対一照合から計算する。`remaining fields` 等の一括行は完成根拠にしない。
- 地域変更は、selector、URL、title、heading、地図、指標、資料、download対象が同じcanonical territory IDになり、loading終了後も一致した時点で完了とする。
- 計画文書の適用根拠は、選択した行政型の権限・manual・formで確認する。別行政型の規則や一般法を、適用様式の根拠へ昇格させない。
- 全対応言語でindicator名・theme・notice・downloadを検査する。意図した原語併記と未翻訳を区別する。
- READMEに記載した開発・build・preview手順も成果物であり、空白画面や古い固定期待値を残さない。
- 国別成果をGit外へ渡す場合も、生成元commit、dataset版、原本hash、未commit差分を機械的に追跡可能にする。

## 再利用する標準制作プロセス

### 1. 対象と作業場所を固定する

国名をISO国IDへ解決し、新しい国別ディレクトリを作る。参照テンプレートURL・commit、公開依頼、成果保存先を開始票へ記録する。テンプレート原本や別国成果へ上書きしない。

### 2. Source preflightを作る

国勢調査・統計局、計画法・手引き、行政コード・境界、分野別省庁、国際的な地方統計候補の所在を列挙する。所在の確認は、原本取得、本文確認、地理照合、指標採用と別状態にする。

Public KitにはJICA対象142か国について、国ID、統計局入口、UNSD、FAOLEX、JICA／外務省、geoBoundaries、SALB／HDX、WDI等の発見用アドレスがある。これは探索開始点であり、142か国の国勢調査表・計画法本文・国内地域データを取得済みという意味ではない。

### 3. 公式目録を閉じる

統計局・国勢調査のcatalogueにある期待資料を `SOURCE_RESOURCE_INVENTORY` へ列挙する。各資料を、統合済み、取得済み未採用、取得不能、制限あり、重複、置換済み、非互換、対象外のいずれかへ処置し、根拠を残す。代表資料だけを確認して全国目録を閉じたとしない。

### 4. 原本の全表・全数値列を棚卸しする

Excelは全sheet、CSV/APIは全field、PDFは目次・付表・継続表を確認する。原名、定義、単位、分子分母、期間、地域粒度、採用指標ID、非採用理由、再配布判断を `SOURCE_TABLE_INVENTORY` に残す。画面へ全列を出す必要はないが、落とした列をなかったことにしない。

### 5. 6分野と計画制度の探索を閉じる

人口、教育、保健・栄養、水・衛生・住宅・エネルギー、生計・貧困・経済、アクセス・インフラ・環境を監査する。利用可能候補を発見したが未統合の状態は完成にしない。法定の計画主体、計画対象区域、適用法令・手引き、必要内容を確認し、計画・予算・実施・評価の資料状態を分ける。

### 6. 地域コードと境界を閉じる

統計表の地域ID、公式コード、地域型、親子関係、有効期間、境界版を対応表へ記録する。未結合地域を数え、統計を保持したまま地図なし表示へ落とす。同名検索や旧親ポリゴンで黙って埋めない。

### 7. 国別3ページを構築する

- Territorial Diagnostic：選択地域について、指標ごとの最新確認値と出典年を表示する。
- Thematic Diagnostic：一指標・一地域型・一比較年・一比較集合で、地図・表・順位・CSVを一致させる。
- Development Plan Materials：制度根拠、取得済み資料、地域診断、出力、明示した不足を選択地域へ連動させる。

地域を選んだら地図、見出し、全指標、資料、出力、URLを即時に更新する。下位選択後に同じ親を再選択しても下位を解除する。内部比較の地図・表への注目は上部の分析対象を変えない。

### 8. 文書と取得物を実生成する

Wordを採用する国では、法・手引きに対応した章立て、選択地域の値、年、出典、地図、必要な図表、根拠付き記述、不足を入れる。テンプレート文、`undefined`、空の指示欄だけの文書を合格にしない。隔離rendererで全ページを画像化し、切れ、重なり、表、図、言語、内容を確認する。画面・CSV・Wordの地域、値、単位、期間、出典、算出状態を照合する。

### 9. 反例を使って操作を検証する

通常地域、資料が多い地域、疎な地域、原表空欄、図形未結合、同名・特別地域型、基礎自治体、全件欠測の比較を試す。親再選択、別地域移動、戻る・進む、共有URL、表示言語、狭幅、地図zoomを確認し、前地域の値・資料・状態が残らないことを確かめる。

### 10. 納品範囲を閉じる

自動テスト、国別検証、受入シナリオ、補助確認票、文書render、公開時のremote hashと公開操作を同じcommit・データ版で記録する。制約付き完成では、取得不能等の根拠、完成させた代替、利用上の制限、次の具体的行動を残す。未処置資料、未棚卸し列、候補未統合、未確認出力が残る場合は完成としない。

### 11. 別の担当が独立監査する

制作者が完成を宣言した後、別のタスク・会話・担当が同じ成果を修正せずに監査する。[独立完成監査票](../../templates/INDEPENDENT_AUDIT.md)を案件の `evidence/INDEPENDENT_AUDIT.md` へコピーし、原資料、正規化データ、3ページ、代表地域の操作、CSV・印刷・Word等の実取得物を確認する。`DELIVERY.json`、緑のテスト、制作者の説明だけを証拠にしない。

判定は `ACCEPT`、`REJECT`、`INCOMPLETE AUDIT` のいずれかとし、blockingまたはmajor findingが残る間は公開しない。`REJECT` は制作者へ戻し、実データ・コード・出力を修正してremediationを記録した後、別監査を再実施する。監査報告だけを整えて合格にしない。

## AreaDataへ採用する内容

### 直ちに共通手順へ採用する

1. **資料目録の閉鎖**：単なる `SOURCES.md` に加え、期待資料ごとの処置を記録する。
2. **原表列の閉鎖**：採用指標だけでなく全数値列の採否を残す。
3. **6分野の探索状態**：候補発見・未統合を完成状態と分ける。
4. **地理閉鎖**：地域数、図形数、未結合ID、コード対応、境界版を記録する。
5. **指標別最新値**：国別Territorial Diagnosticでは年選択を要求せず、値ごとに実際の年を表示する。
6. **同年比較**：Thematic Diagnosticの地図・表・順位・CSVは一つの共通比較年へ揃える。
7. **出力一致**：画面、CSV、Markdown／HTML、採用したWord/PDFの内容を実物で照合する。
8. **完成判定**：初期生成・CI成功・表示成功と、地方計画に使える完成を分ける。
9. **公開判定**：Local、GitHub、Hosting、Publicを分け、公開時はremote read-backと実画面を確認する。
10. **AI共通契約**：Antigravity、Gemini、Claude、Codexで入口文が違っても、完成条件を弱めない。
11. **独立監査**：制作者と別の担当が原資料・画面・出力を監査し、`ACCEPT` 前は公開しない。
12. **導出型gate**：自己申告欄とファイル存在ではなく、元値と成果物から意味・年・集合・算出・内容を検証する。

### AreaDataの役割に合わせて適用範囲を変える

| Kitの方針 | AreaDataでの扱い |
|---|---|
| 国別3ページから年selector・履歴導線を外す | 国別の通常診断に採用。`/database/`の研究用検索、世界・大陸・広域の期間比較からは外さない |
| 指標ごとに最新値を表示 | 地域プロフィールに採用。複数国の順位・集計では同年比較または構成年付き混合基準年を明示する |
| 英語Wordを生成 | 共通の必須言語にしない。国別制度・利用者に必要な言語と形式で作り、採用時だけrender gateを課す |
| 3ページを国別独立サイトとして公開 | AreaDataでは同じ国datasetを世界入口から接続する。世界datasetへ国内値を自動マージしない |
| 142か国のsource-address preflight | 所在調査の加速に利用する。取得・本文確認・地域照合・採用の証拠としては使わない |

## Public Kitから参照する再利用データ

次の3ファイルをcommit固定・hash付きで `config/external-source-registries.json` に登録した。大きなpreflight本体をこのリポジトリへ複製せず、国別案件の開始時に参照版とhashを確認して利用する。

- JICA対象142か国の国ID・監督事務所台帳
- 142か国の発見用source preflight
- ドミニカ共和国、ウガンダ、ラオス、バングラデシュの詳細な参照事例

この台帳は世界の全country/area台帳ではない。AreaDataの世界入口はUN M49台帳を維持し、JICA対象かどうかを別属性として扱う。

## 今回記録したが、実装済みとはしないもの

- このAreaDataリポジトリには、Public Kitと同等の `verify-delivery` 自動ゲートをまだ移植していない。
- `verify-delivery` 相当を移植するときも、フィリピンで判明した意味・年・比較集合・文書内容の検査は別途実装が必要である。
- AreaDataの国別Word生成、全ページrender、Public hash照合を全国家で実施したわけではない。
- 142か国のpreflightは所在台帳であり、142か国の国勢調査・計画法・地方統計の取得完了ではない。
- ラオスとバングラデシュの2例は、他国の制度、言語、境界、公開条件を網羅しない。
- 現地自治体職員・研究者による実利用試験は両国とも完了していない。

以上を、既存のウガンダ教訓、42受入シナリオ、国別作業手順と併用する。各国の画面を新しい固定テンプレートとして複製せず、完成工程と証拠構造を共通化する。
