# 共通デザイン・機能仕様

版：0.2（2026-09-13、上位地域の再選択を明文化）。DDPTの実装・添付レビュー・ウガンダの教訓から作成した改善モデル案。現行DDPTの全画面がこの仕様に適合するという記述ではない。

## 1. ページの目的と標準構成

共通化するのはページの役割と利用者の予測できる操作である。全ページを同じ地図＋カード配置にそろえることは要求しない。

| ページ群 | 利用者の問い | 標準構成 | 国別の可変部分 |
|---|---|---|---|
| ホーム | どこから調べるか | 「地域から調べる」「テーマから比べる」を上部へ。投資・要求・計画・用語・更新情報へ到達できる | 名称、ブランド、導入するモジュール |
| 地域診断 | この地域はどのような状況か | 短い見出しと操作→左に地域選択・基本情報／右に位置図→人口・分野別診断→比較・出典。章目次で移動 | 分野、図表、データがある粒度、比較対象 |
| テーマ別診断 | この指標で地域にどんな違いがあるか | テーマ・指標・期間・粒度→全国／比較集合の概要→地図と検索・ランキング・選択地域詳細→分布・利用可能なら推移 | 指標、期間、地理粒度、比較条件 |
| 公共投資・財政 | どこに、何の事業と資金があるか | 地域・期間・分野条件→対象が分かる概要→地図／一覧→事業・財源・資料。計画画面へ接続 | 独立モジュールか統合欄か、事業分類、財政年度、予算／実績 |
| 住民要求・参加記録 | 誰から、何が提案・決定されたか | 対象条件→件数と範囲→要求一覧・出典・状態→計画の課題整理 | 参加制度、公開範囲、要求分類。資料がなければ保留 |
| 計画・資料 | この地域の資料から計画作業をどう始めるか | 収録状況の概要→地域選択→地図と選択地域の資料→既存計画・財政資料・ベース文書取得 | 計画の種類・階層・周期、法定様式、章構成、権限 |
| 共通支援 | 根拠・定義・更新状況を確認したい | 用語集、出典台帳、資料日付、利用方法。運用者には更新・検証機能 | 言語、機関、管理体制、更新経路 |

地域診断・テーマ比較・計画資料を共通の中心とする。投資・要求は計画につながる役割を保持し、独立ページの有無は国の資料と利用業務に応じて決める。DDPTの全モジュール数やウガンダの３ページを、世界共通の固定数にしない。

## 2. 共通操作契約

契約は採用する機能に適用する。作業メモ・保存・文章生成・各出力形式の実装自体は国別に決め、受入のためだけに新機能を必須化しない。未採用なら理由と代替作業を記録する。既存機能を削る場合には互換性と利用者への影響を確認する。

### C01 地域選択と表示の一致

- 地図、階層選択、地域名・コード検索、一覧のどこから選んでも同じ対象になる。
- 選択だけで、見出し、基本情報、地図の選択と表示範囲、各図表、資料・出力対象が連動する。追加の「選択地域へズーム」ボタンは補助操作とする。
- テーマ・指標は地域を変えても保持する。選択先に値がなければ、その指標の欠測を表示する。
- 「全国へ戻る」は全国の範囲と対象を回復する。地図のパン・ズームだけで分析対象や指標を変えない。
- 地域をA→Bへ素早く変えたとき、遅れて届いたAの応答をBの表示へ混ぜない。Bの読込中・失敗中にAの文書をBとして取得させない。
- 境界がない場合も一覧・検索で選べる。階層・地図クリックに依存して対象へ到達不能にしない。

#### 上位地域を選び直したときの優先規則

**最後に明示選択した地域が分析対象となる。** 市・県を選んだ後にRegion等の上位を選んだら、その配下の市・県・下位地域の選択を解除し、上位地域全体を表示する。上位が常に下位へ優先する固定ルールではなく、その後で下位を選べば下位が新しい対象となる。

| 操作 | 新しい分析対象 | 下位選択の状態 |
|---|---|---|
| 市A → その市と同じSubregionを明示選択 | Subregion全体 | 市Aとそれ以下を解除 |
| 市A → その市と同じRegionを明示選択 | Region全体 | Subregion、市Aとそれ以下を解除 |
| 市A → 別Regionを選択 | 選んだRegion全体 | 以前の配下選択を解除 |
| 上位全体 → 市Bを選択 | 市B | 市Bの所属先を整合させる |
| 子選択欄の「上位全体」を選択 | その欄の親地域全体 | 子とそれ以下を解除 |

選択中の市の所属Regionが欄に表示されていても、**そのRegion全体を選び直せる操作**を提供する。ネイティブselectで同じvalueが選択済みだとchangeが発生しないため、所属表示を選択済みの親全体と同一扱いしない。所属表示と「Whole／全体」の選択肢を区別する等、実際のドロップダウン操作で再選択を成立させる。個別地域へ固定する隠れた状態を残さない。

この操作で見出し・基本値・地図・全分野の図表・資料・出力対象・URLを一つの選択IDへ揃える。指標・年は保持し、親の観測がなければ親名と欠測を表示する。上位の選択自体を、子の候補を絞るだけの操作にしない。テーマ比較の「比較する粒度」は分析対象と別の意味なので明示する。行政階層数やRegion等の名称は国別設定とし、統計的な所属を行政権限と同一視しない。

### C02 ページ移動・共有・保存

- 地域の詳細リンクは国、地域型、公式コード、境界版を引き継ぐ。対応する指標・期間・比較条件も移行先で意味が一致する範囲で保持する。
- 移行先がその粒度に未対応なら、対象名を残して理由と対応する地域の選択を示す。首都や別地域へ無言で切り替えない。
- 全国へのリセット専用リンクを設ける場合は、その役割を明示し、通常のページメニューや地域別リンクと区別する。
- ブランド／全国の初期入口は全国・既定条件へ戻り、通常のページメニューは現在の地域・指標・期間を保持する。地域別の保存メモは入口への復帰で消さない。
- 共有URL、再読込、戻る／進むで選択を復元する。無効・旧コードは移行対応表で説明し、複数候補なら選択を求める。
- 分析条件と地域別の作業メモを分ける。地域メモの読込で現在の指標を上書きしない。保存形式の版、国と地域の識別、移行、バックアップ・復元を用意する。

### C03 集計・比較・フィルターの範囲

- 全KPI・凡例・ランキング・表・出力には、地域範囲、期間、定義、データ版を追跡できる情報を持たせる。
- 同一定義・同一対象・同一版の数はページ間で一致させる。異なる基準日の計画スナップショットを使う場合は、最新値との差の理由を表示する。
- 「全国の概要」と「選択地域／絞り込み結果」をラベルと位置で分ける。全国集計を残すこと自体は不具合ではない。
- 地域を探す検索は、通常、表示する行だけを絞る。比較対象を変えるフィルターとは別に扱い、適用範囲を示す。
- 選択地域が初期順位一覧外でも、詳細と順位への移動を提供する。全地域へ到達できる。
- 地図で地域を選んだら、順位表の対応行を表内部で自動表示する。順位検索がその行を隠す場合だけ検索を解除し、比較集合・順位・中央値を変更しない。欠測行も到達可能にし、数値順位を与えない。自動移動でページ全体の閲覧位置を飛ばさない。
- 全国公式値、地方値の合算、自治体中央値を区別する。収録率は「値がある地域数／対象地域数」、母集団や除外条件も示す。
- 率の上位集計には、同一定義・期間・範囲の正確な分子と分母、重複しない完全な所属集合を使う。率の平均、丸め率からの分母逆算、広域の分母の地方への割当てをしない。PDF等で分母を追加取得する場合は表・頁・範囲の一致を記録する。全国値と地方合算が同じ丸め表示でも別系列を保持する。
- 地図の階級が全国固定か比較集合ごとの再計算かを明示する。値の大小を根拠なく良否・優先順位と読み替えない。

### C04 出典・状態・欠測

- 図の近くに出典名、対象年、単位、重要な定義を短く残す。長い方法論、原表の位置、変換履歴は展開して確認できるようにする。
- 真のゼロ、欠測、非該当、未確認、読込中、取得失敗を区別し、文字・記号を併用する。
- 確認済みと要確認に同じチェック記号を使わない。数値の有無、証拠の確かさ、取得処理の状態は別の軸で管理する。
- 資料の「リンク確認」「本文取得」「抽出済み」と、制度の「策定済み」「承認済み」は別項目にする。
- 全国値だけ存在するときは全国参考情報として示す。選択地方の値へ代用しない。

### C05 取得・文章生成・計画作業

- 文書を案内する場所には、取得操作または必要条件を示す。未認証ならログイン後の取得を案内し、認証後も地域を保持する。UIの表示条件とサーバーの権限検証を分ける。
- 取得可能、準備中、準備失敗、未提供を明示する。クリック不能なら理由と次の操作を示す。
- Word/PDF/CSV/PNGは提供できる形式を揃った位置・表現で示す。原図しかない場合に数値CSVを作る等、根拠のない形式追加をしない。
- ファイルの対象地域・期間・指標・単位・出典を画面と照合する。文書が固定版ならその版を取得前に示す。画面の新図と旧文書図の違いは無説明で残さない。
- 文章診断は、開始条件・進行・失敗時の次の操作を示し、入力と取得済み根拠を保持する。再試行で前の成功文を無言で消さない。
- 文章やベース文書は出典付きの草案。統計的な事実、職員の提案、住民の提案・合意、公式の決定を別記録にし、AIが合意・承認を作らない。

### C06 情報配置と視覚ルール

- 共通ヘッダー、現在のメニュー、短いページ見出し、選択地域、主要操作をそろえる。長いタイトルや説明を重ねて分析領域を押し下げない。
- 地域診断は選択・基本情報と位置図を上部に、テーマ診断は条件と全国比較を上部に置く。計画ページは地域と資料への到達を中心にする。
- 分野の見出し帯、控えめな枠線・角丸、読みやすい図表を共通の語彙にする。ブランド色は国別に変更可能だが、状態色の意味を逆転させない。
- 章目次、現在位置、先頭／次の作業への移動を提供する。豊富な図表を削って短くすることを標準対応にしない。印刷では必要な全章に到達できる。
- 図表の種類は数値の意味で選ぶ。実数と全国総数の比較で地方の棒が読めなくなる場合は、KPI・構成・同種地域内の分布を使う。
- 人口ピラミッド等の年次対比を提供する場合は最新年を先に、過去年をグレースケールで続ける（PCは左→右、狭幅は上→下）。地方原図と全国数値図、異なる年齢階級を区別し、未取得年は欠測にする。通常の時系列の時間軸まで逆順にはしない。
- 湖・海岸線は出典と地図縮尺に合う任意の背景層として扱う。水面上を横切る行政境界を破損と決めつけず、原境界・ID・所属・値を保つ。背景層は行政境界と同じ投影・表示範囲を使い、クリックを透過し、島の穴を保持する。表示切替で対象や順位を変えない。原図やPNG等に背景を含む場合は出典を付け、画面・文書の対応範囲を記録する。

以下は**実測したDDPT値ではなく、各国の試作で検証する初期案**。狭い文字体系や長い翻訳に合わせて変更できる。

| 項目 | 出発点 | 判定の重点 |
|---|---|---|
| 本文領域 | PC最大幅1120～1200px、外側余白16～24px | 同じ幅の基準画像で情報の優先順位を比較する |
| 文字 | 本文14～16px、ページ見出し22～26px | 現地言語、文字拡大、図の文字が読めること |
| 地域診断上部 | PCで選択・基本情報約1/3、位置図約2/3 | 初期画面で主要操作と地図の主要部分が分かること |
| 狭い画面 | 上から条件→概要→図／一覧→詳細へ積む | 横スクロールの強制や取得ボタンの隠れを避ける |
| デザイントークン | 色、文字階層、余白、枠線、角丸、focus、状態表示を共通定義 | 数値を決めたら国別差分に理由を記録する |

### C07 アクセシビリティ・言語・接続条件

- 地域選択と入力欄に関連付けられたラベルを付ける。キーボード操作、見えるフォーカス、地図以外の選択手段を用意する。
- 国・言語別の日付、桁区切り、小数、通貨、単位を共通の整形規則で出す。多言語の長いラベルや必要な右から左への表示も国別に検証する。
- 1366×900前後、幅768px、幅375px、幅320px、実際の200%文字拡大を検証する。画面幅変更だけで文字拡大の検証を済ませない。地図等の二次元表示で再配置に例外が必要なら、理由と代替操作を記録する。
- 想定回線と端末は国別に決め、初回データ量と主要操作の待ち時間を測る。重い資料は必要時取得にし、背景地図の障害時も地域選択と取得済み情報を使えるようにする。
- 自動チェックだけで正式なアクセシビリティ適合や現場での使いやすさを宣言しない。

## 3. 変更の判断

翻訳、制度名、指標、適切な図表、期間、粒度、対応表、必要なレイアウト調整は、根拠と合意した国別規則の範囲内で進める。

ページの目的を変える統合、地域選択後に追加操作を要求する変更、フィルターの意味変更、主要機能削除、保存・URLの互換性破壊は共通モデルへの変更となる。既存の依頼で認められていなければ、画面差分・利用者への影響・代替案を作り、判断を得てから該当部分へ適用する。

見た目を現行DDPTへ合わせるためにF01～F09の問題を再現してはならない。対応は[所見台帳](REVIEW_TRACEABILITY.md)、検証は[受入記録](../templates/ACCEPTANCE.md)で追跡する。
